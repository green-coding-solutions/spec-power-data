System Under Test Notes
  • Each JVM instance was bound to 4 logical processors
  • SPECpower_ssj.props input.load_level.number_warehouses set to 640 due to a known inconsistency in processor reporting with this Java version
  • Using Windows PowerShell, set the following powercfg properties
  • powercfg /setacvalueindex scheme_current sub_processor CPOVERUTIL 60
  • Powercfg /setacvalueindex scheme_current sub_processor PERFBOOSTMODE 3
  • powercfg /setacvalueindex scheme_current sub_processor CPMINCORES1 100
  • powercfg /setacvalueindex scheme_current sub_processor CPMINCORES 100
  • powercfg /setacvalueindex scheme_current sub_processor PERFDECTHRESHOLD 95
  • powercfg /setacvalueindex scheme_current sub_processor PERFINCTHRESHOLD 98
  • Powercfg /setactive scheme_current
  • Power Plan Minimum processor state set to 0%
  • Power Plan Maximum processor state set to 100%
  • Using the local security settings console, "lock pages in memory" was enabled for the user running the benchmark
  • Hard Disk set to turn off after 1 minute
  • The system ROM used for this result contains AMD AGESA version 5910100B00000000 for the AMD EPYC 9845 processor.
