                            System Under Test Notes                            

Set the following options in OS.                                               
* "Turn off hard disk after = 1 Minute"                                        
* "Minimum processor state = 0%"                                               
* "Turn off display after = 1 Minute"                                          
Execute the following commands in OS.                                          
* "POWERCFG /SETACVALUEINDEX SCHEME_CURRENT SUB_PROCESSOR PERFINCTHRESHOLD 95" 
* "POWERCFG /SETACVALUEINDEX SCHEME_CURRENT SUB_PROCESSOR PERFINCTIME 40"      
* "POWERCFG /SETACVALUEINDEX SCHEME_CURRENT SUB_PROCESSOR PERFINCTHRESHOLD 93" 
* "POWERCFG /S SCHEME_CURRENT"

for the user running the benchmark.                                            
* Benchmark was started via Windows Remote Desktop Connection.                 
* SPECpower_ssj.props input.load_level.number_warehouses set to 16.            
* The system ROM used for this result contains Intel microcode version         
000000002C010000 for the Intel Xeon 6369P processor.
