                            System Under Test Notes                            

* SPECpower_ssj.props input.load_level.number_warehouses set to 344 due to a   
known inconsistency in processor reporting with this Java version.             
* The test was started via Remote Desktop                                      
* JVM Settings:                                                                
* Each JVM instance was affinitized to 4 threads.                              
* Using the local security settings console, "lock pages in memory" was enabled
for the user running the benchmark.                                            
* Windows Power Saver Settings:                                                
* Turn off Hard Disk after 1 minute                                            
* Turn off Display after 1 minute                                              
* Using Windows PowerShell, set the following powercfg properties:powercfg /qh 
scheme_current sub_processor perfboostmode                                     
* powercfg /setacvalueindex scheme_current sub_processor perfboostmode 3       
* powercfg /qh scheme_current sub_processor perfboostmode                      
* powercfg /setactive scheme_current                                           
* The system ROM used for this result contains Intel microcode version         
0x1000380 for the Intel Xeon 6787P processor.
