                            System Under Test Notes                            

* Run was started via psexec script                                            
* Windows firewall was disabled                                                
* Using the local security settings console, "lock pages in memory" was enabled
for the user running the benchmarkSPECpower_ssj.props                          
input.load_level.number_warehouses set to 144 to detect the full number of     
available processors on the SUT                                                
* Windows Power Options = Power Saving                                         
* Turn off Display = 1 Minute                                                  
* Turn off hard disk = 1 Minute                                                
* Processor power management = Minimum Processor State = 0%                    
* Maximum Processor State = 100%                                               
* PCI Express Power Management = Maximum Power Savings                         
* powercfg /qh scheme_current sub_processor perfboostmode                      
* powercfg /setacvalueindex scheme_current sub_processor perfboostmode 3       
* powercfg /setactive scheme_current                                           
* The system ROM used for this result contains Intel microcode version         
0000000080030001 for the Intel Xeon 6780E Processor
