                            System Under Test Notes                            

Set the following options in OS.                                               
* "Turn off hard disk after = 1 Minute"                                        
* "PCI Express Link State Power Management = Maximum power savings"            
* "Minimum processor state = 0&percnt;"                                        
* "Turn off display after = 1 Minute"Execute the following commands in OS.     
* "POWERCFG /SETACVALUEINDEX SCHEME_CURRENT SUB_PROCESSOR PERFINCTHRESHOLD 90" 
* "POWERCFG /SETACVALUEINDEX SCHEME_CURRENT SUB_PROCESSOR PERFDECTHRESHOLD 80" 
* "POWERCFG /SETACVALUEINDEX SCHEME_CURRENT SUB_PROCESSOR IDLESCALING 1"       
* "POWERCFG /SETACVALUEINDEX SCHEME_CURRENT SUB_PROCESSOR PERFBOOSTMODE 4"     
* "POWERCFG /SETACVALUEINDEX SCHEME_CURRENT SUB_PROCESSOR PERFDECTIME 1"       
* "POWERCFG /S SCHEME_CURRENT"                                                 
* Using the local security settings console, "lock pages in memory" was enabled
for the user running the benchmark.                                            
* Benchmark was started via Windows Remote Desktop Connection.                 
* SPECpower_ssj.props input.load_level.number_warehouses set to 256.           
* The system ROM used for this result contains Intel microcode version         
00000000A0010021 for the Intel Xeon Platinum 8592+ processor.
