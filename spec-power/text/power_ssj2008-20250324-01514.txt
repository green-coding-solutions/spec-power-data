                            System Under Test Notes                            

* Each JVM instance was bound to 2 physical processors                         
* SPECpower_ssj.props input.load_level.number_warehouses set to 288 due to a   
known inconsistency in processor reporting with this Java version.             
* Using the local security settings console, "lock pages in memory" was enabled
for the user running the benchmark.                                            
* Run initiated via Windows Remote Desktop Connection                          
* Hard Disk set to turn off after 1 minute                                     
* Minimum processor state set to 0%                                            
* Display set to turn off after 1 minute                                       
* powercfg /qh scheme_current sub_processor perfboostmode                      
* powercfg /setacvalueindex scheme_current sub_processor perfboostmode 3       
* powercfg /setactive scheme_current                                           
* The system ROM used for this result contains Intel microcode version 03000330
for the Intel Xeon 6780E processor
