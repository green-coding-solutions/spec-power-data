                            System Under Test Notes                            

Set the following options in OS.                                               
* "Turn off hard disk after = 1 Minute"                                        
* "Minimum processor state = 0&percnt;"                                        
* "Turn off display after = 1 Minute"                                          
Execute the following commands in OS.                                          
* "POWERCFG /SETACVALUEINDEX SCHEME_CURRENT SUB_PROCESSOR PERFINCTHRESHOLD 96" 
* "POWERCFG /SETACVALUEINDEX SCHEME_CURRENT SUB_PROCESSOR PERFDECTHRESHOLD 95" 
* "POWERCFG /SETACVALUEINDEX SCHEME_CURRENT SUB_PROCESSOR PERFINCTIME 25"      
* "POWERCFG /S SCHEME_CURRENT"                                                 
* Using the local security settings console, "lock pages in memory" was enabled
for the user running the benchmark.                                            
* Benchmark was started via Windows Remote Desktop Connection.                 
* SPECpower_ssj.props input.load_level.number_warehouses set to 24.            
* The system ROM used for this result contains Intel microcode version         
0000000037010000 for the Intel Xeon 6377P processor.
